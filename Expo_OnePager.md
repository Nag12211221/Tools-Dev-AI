# 🛡️ CAN Bus Spoofing Diagnostic Tool

**Automated detection of malicious message injection on the CAN network.**

---

## 🚀 Quick Start

### GUI Tool
1. Download `CAN_Spoofing_Diagnostic_Tool.html`
2. Double-click to open in **any modern browser**
3. Click **"Load Demo Data"** → then **"Analyze Log"** to see it in action
4. Or paste/upload your own CAN log files (.asc, .csv, .txt)

> ✅ **Runs fully offline** — All processing happens locally; no data is sent anywhere.

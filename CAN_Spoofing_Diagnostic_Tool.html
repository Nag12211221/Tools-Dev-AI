How It Works

This tool detects spoofed CAN messages by analyzing inter-message timing intervals. Legitimate ECUs transmit at predictable periodic rates. Injected messages arrive faster than expected, violating timing constraints. The tool classifies each CAN ID based on observed intervals vs. configured thresholds.
